# DeepSeek Chat Demo（美化重写版）

基于 DeepSeek API 的纯静态聊天前端。无后端、无遥测，浏览器直连 API，所有会话与附件保存在本机 IndexedDB，API Key 只存本机 localStorage。

在线体验：<https://by654.github.io/deepseek-chat-demo/>

## 与官方 demo 的差异

这一版在官方 chat-demo 基础上做了一轮界面重写与功能补全，主要改动：

### 界面修复

| 问题 | 处理 |
| --- | --- |
| 动画几乎不可感知、切换生硬 | 统一过渡令牌（`--ds-transition-duration` / `--ds-ease-*`），按钮、气泡、主题切换、弹窗均带过渡；尊重 `prefers-reduced-motion` |
| 输入框 placeholder 下方多一条横线 | 去掉伪元素装饰与输入区边框，仅保留卡片外边界 |
| 弹窗正文文字贴边 | 弹窗内容区统一 24px 内边距（移动端 20px），删除会话等确认弹窗同步修正 |
| 桌面端会话三点菜单失焦后飘到左上角 | 浮层改用 `useAnchoredPosition` 同步测量 + ResizeObserver 跟踪，打开期间不再丢锚点 |
| 设置项全部堆在下方 | 设置改为左右两列：左导航 + 右内容，桌面 780×512 居中弹窗 |
| 移动端消息区页边距过小 | 移动端断点下统一气泡与操作按钮外边距，触摸目标不小于 44px |
| 移动端设置页签过多 | 导航条横向滚动，不再换行挤压内容 |

### 新增功能

- **用量与费用**：每条回答下方显示输入/输出 token 与估算费用；输入区上方显示本会话累计 token 与上下文剩余额度
- **余额显示**：输入区功能栏显示当前 API 余额，支持点击刷新与自动刷新（设置中可配刷新间隔）
- **框选引用**：在回答中选中文字，浮出「引用」按钮，一键写入输入框（引用块格式）
- **主题**：内置 13 套主题色预设（含官方蓝），支持自定义任意 `#rrggbb` 颜色
- **导出 Word**：每条回答带「导出文档」按钮，可导出为 `.doc`；设置中可开关并配置字体、字号、颜色、是否附元信息
- **淡化输出**：新消息淡入效果，设置中可关闭
- **回到最新**：离开底部一定距离后出现向下箭头，点击平滑回到底部
- **记忆聊天位置**：重新打开网页时在页面中间贴一张小卡片，询问是否回到上次聊天与阅读位置；设置中可选「每次都问 / 直接打开 / 不询问」
- **字体缩放**：正文、代码块、思考过程可分别按百分比缩放（60%~200%）
- **自定义提示词**：可设置每轮都附加的系统提示词，以及仅在会话首次提问时附加的引导内容
- **消息排队**：AI 流式输出期间输入框不锁定，新消息进入队列；支持编辑、删除队列项，可配置「全部保留依次发送」或「只保留最后一条」
- **模型切换**：输入框内直接切换 `deepseek-flash` / `deepseek-v4-pro`
- **脱敏日志**：设置中一键导出脱敏后的运行日志（自动遮蔽 `sk-` 与 Bearer 凭证）
- **首次引导**：首次打开时展示引导页，填写 API Key 与称呼后即完成设置，取代原数据管理弹窗
- **合并导入**：导入历史 ZIP 时可选择「与本地合并」或「整体替换」；同一会话 ID 冲突时可选择保留两条、保留本地或保留导入版本

## 本地运行

需要 Node.js 20+ 与 pnpm。

```bash
pnpm install
pnpm dev        # 开发服务器
pnpm build      # 生产构建，产物在 dist/
pnpm type       # 类型检查
pnpm lint       # 代码检查
```

构建产物是纯静态文件，可直接用任意静态服务器托管；也可以双击 `dist/index.html` 以 `file://` 方式使用。

局域网预览（手机与电脑同一网段）：

```bash
cd dist
python -m http.server 5001 --bind 0.0.0.0
```

## 部署到 GitHub Pages

仓库内已包含 `.github/workflows/pages.yml`：推送到 `main` 后自动类型检查、构建并发布到 Pages。首次使用需在仓库 Settings → Pages 把 Source 设为 GitHub Actions。

## 使用说明

1. 在 <https://platform.deepseek.com> 申请 API Key
2. 首次打开按引导填入 Key，或稍后在「设置 → 数据管理」补充
3. Key 仅保存在本机 localStorage，不上传任何服务器

## 技术栈

TypeScript + React 18 + CSS Modules + Zustand + rspack + pnpm。不引入重型 UI 框架，样式全部通过 CSS 变量做主题化。

## 目录结构

```
src/
  app/            应用入口、主题与配色预设
  components/     界面组件（聊天区、输入区、设置、弹窗、引导）
  i18n/           中英文文案
  services/
    api/          请求与 SSE 事件解析
    chat/         会话状态、消息、草稿、队列、记忆
    export/       Word 导出
    logs.ts       脱敏日志
    settings.ts   本地设置读写
```
