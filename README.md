# DeepSeek Chat Demo（美化重写版）

基于 DeepSeek API 的聊天前端。默认纯静态、无遥测，浏览器直连 API，所有会话与附件保存在本机 IndexedDB，API Key 以 AES-GCM 加密后保存在本机。登录 Supabase 账号后可选用云端会话同步、附件原件同步、只读分享、公告、反馈、管理员看板与两步验证。

全站名称统一为「DeepSeek 美化版」，覆盖页面标题、侧栏品牌、脱敏日志标题、导出文档属性与导出文件名。

在线体验：<https://by654.github.io/deepseek-chat-demo/>

## 与官方 demo 的差异

这一版在官方 chat-demo 基础上做了一轮界面重写与功能补全，主要改动：

### 界面修复

| 问题 | 处理 |
| --- | --- |
| 动画几乎不可感知、切换生硬 | 统一过渡令牌（`--ds-transition-duration` / `--ds-ease-*`），按钮、气泡、主题切换、弹窗均带过渡；尊重 `prefers-reduced-motion` |
| 减少动效只覆盖全局样式表 | 新增的交互动画逐个补 `@media (prefers-reduced-motion: reduce)`：下拉菜单（`Select.module.css`）、输入区与上传转圈（`ChatInput.module.css`）、设置项与进度条（`Settings.module.css`）、手机端箭头面板（`QuickPanel.module.css`），命中时动画与过渡一律置 `none` |
| 手机端功能栏按钮挤压重叠 | 窄屏把模型选择与余额收进发送键左侧箭头面板（`QuickPanel`），功能栏只保留上传、语音、发送，按钮间距与触控尺寸重排 |
| 手机端设置弹窗没有铺满 | 窄屏断点下设置弹窗改为全屏：`height/max-height: 100dvh`，桌面端保持 780×512 居中并留 32px 边距 |
| 输入框 placeholder 下方多一条横线 | 去掉伪元素装饰与输入区边框，仅保留卡片外边界 |
| 弹窗正文文字贴边 | 弹窗内容区统一 24px 内边距（移动端 20px），删除会话等确认弹窗同步修正 |
| 桌面端会话三点菜单失焦后飘到左上角 | 浮层改用 `useAnchoredPosition` 同步测量 + ResizeObserver 跟踪，打开期间不再丢锚点 |
| 设置项全部堆在下方 | 设置改为左右两列：左导航 + 右内容，桌面 780×512 居中弹窗 |
| 移动端消息区页边距过小 | 移动端断点下统一气泡与操作按钮外边距，触摸目标不小于 44px |
| 移动端设置页签过多 | 导航条横向滚动，右侧用渐隐提示还有更多页签；主色色块同样支持横向滑动 |
| 竖屏设置文字错位 | 标题、说明与右侧控件统一按顶部对齐，主题选项改为等宽三列 |
| 输入框向上展开遮住消息 | 消息区与输入区改为上下分栏，输入框只在自身区域展开，不再覆盖消息 |
| 浅色主题边栏发灰 | 边栏改用更轻的蓝白底色，与白色画布、分隔线形成清晰层次 |

### 新增功能

- **用量与费用**：每条回答下方显示输入/输出 token 与估算费用；输入区上方默认只保留一行摘要（总 token、费用、上下文水位、闲峰标签），点击展开本会话明细，竖屏下不再把一长串数字全部铺在输入框上方
- **API 调用统计**：记录对话、余额查询、语音识别、语音合成、文件上传/删除与密钥校验的请求次数和失败次数，持久化在本机；会话明细与「设置 → 用量与统计」都能查看，其他接口按官方口径标注为未单列计费
- **官方单价与闲峰计价**：内置 `deepseek-flash` / `deepseek-v4-pro` 两档官方单价（缓存命中、缓存未命中、输出分别计价），高峰为北京时间周一至周五 9:00–12:00、14:00–18:00（法定节假日除外），其余为闲时；设置中可在「自动 / 闲时 / 高峰」间切换，自动模式每分钟重判一次时段
- **余额显示**：输入区功能栏显示当前 API 余额，支持点击刷新与自动刷新（设置中可配刷新间隔）；手机端在箭头面板内显示金额
- **框选引用**：在回答中选中文字，浮出「引用」按钮，一键写入输入框（引用块格式）
- **主题**：内置 4 套界面风格（官方蓝白、青灰、暖砂、石墨）与 13 套主色预设；主色支持直接输入 `#rrggbb`，不调用浏览器取色器
- **动效**：侧栏收起/展开、移动端抽屉、弹窗退场与 Toast 退场都有过渡；系统开启「减少动态效果」时自动缩短或关闭位移动画
- **导出 Word**：每条回答带「导出文档」按钮，导出真正的 `.docx`（OOXML 包，含 `[Content_Types].xml`、`_rels/.rels`、`word/document.xml`、`word/styles.xml`、`docProps`），Word / WPS / Pages 均可直接打开；设置中可开关并配置字体、字号、颜色、是否附元信息
- **兼容最新官方导出**：导入聊天记录时放宽 schema 校验，字段新增或缺失、版本号高于当前实现都不再直接拒绝，`manifest.json` 缺失时按会话文件自动识别，导入失败会给出具体原因
- **时段订阅开销**：闲峰时段判定改为全局单一定时器 + `useSyncExternalStore`，档位未变化时不会触发重渲染
- **淡化输出**：新消息淡入效果，设置中可关闭
- **回到最新**：离开底部一定距离后出现向下箭头，点击平滑回到底部
- **记忆聊天位置**：重新打开网页时在页面中间贴一张小卡片，询问是否回到上次聊天与阅读位置；设置中可选「每次都问 / 直接打开 / 不询问」
- **字体缩放**：正文、代码块、思考过程可分别按百分比缩放（60%~200%）
- **自定义提示词**：可设置每轮都附加的系统提示词，以及仅在会话首次提问时附加的引导内容
- **消息排队**：AI 流式输出期间输入框不锁定，新消息进入队列；支持编辑、删除队列项，可配置「全部保留依次发送」或「只保留最后一条」
- **模型切换**：输入框内直接切换 `deepseek-flash` / `deepseek-v4-pro`
- **脱敏日志**：设置中一键导出脱敏后的运行日志（自动遮蔽 `sk-` 与 Bearer 凭证）
- **首次引导**：首次打开时展示引导页，填写 API Key 与称呼后即完成设置，取代原数据管理弹窗
- **合并导入**：导入历史 ZIP 时可选择「与本地合并」或「整体替换」；同一会话 ID 冲突时可选择保留两条、保留本地或保留导入版本
- **进度反馈**：历史导出与导入全程显示进度条（导入含解包、合并与冲突处理阶段）

## 本地运行

需要 Node.js 20+ 与 pnpm。

```bash
pnpm install
pnpm dev        # 开发服务器
pnpm build      # 生产构建，产物在 dist/
pnpm type       # 类型检查
pnpm lint       # 代码检查
```

构建产物是纯静态文件，可直接用任意静态服务器托管；也可以双击 `dist/index.html` 以 `file://` 方式使用。

局域网预览（手机与电脑同一网段）：

```bash
cd dist
python -m http.server 5001 --bind 0.0.0.0
```

然后访问 `http://<本机局域网 IP>:5001`。

## Supabase 云端能力

应用内置 Supabase 账号体系（用户名 + 密码，映射为项目内的伪邮箱），支持：

- **多端会话同步**：登录后在侧栏点击「同步」，或在窗口聚焦 / 网络恢复时自动增量同步；实时订阅其他设备的改动
- **附件原件同步**：附件上传到私有存储桶 `chat-attachments/<用户 id>/`，其他设备打开会话时自动下载缺失原件
- **只读分享**：会话标题栏菜单 →「分享会话（只读链接）」；支持访问密码、1/7/30 天有效期、查看次数与撤销；拿到链接的人无需登录即可阅读，登录后可导入为自己的会话
- **公告与反馈**：管理员发布公告后显示在所有用户主界面顶部；登录用户可在账号区提交反馈
- **管理员面板**：概览（用户 / 会话 / 分享 / 反馈 / 存储 / 近 7 日活跃）、用户启用停用删除、公告、反馈处理、审计日志
- **两步验证**：个人资料中绑定 TOTP 验证器；绑定后登录会要求输入 6 位动态验证码

首次使用需在 Supabase 控制台 → SQL Editor 中依次执行：

1. `supabase/user_admin.sql`：账号档案、用户自助资料、管理员用户管理
2. `supabase/features.sql`：分享、附件存储桶与策略、公告、反馈、审计、管理员看板、语义检索预留表

两个脚本都是幂等的，可重复执行。执行完刷新页面即可；未执行时管理员面板与云同步页会给出初始化提示。

Supabase 项目地址与 publishable key 在 `src/services/supabase/config.ts` 中配置。

仍需服务端协议的少数能力（真正的语义向量检索、多人实时协作编辑、端到端加密）当前版本只预留了数据结构，尚未接入前端。

## 使用说明

1. 在 <https://platform.deepseek.com> 申请 API Key
2. 首次打开按引导填入 Key，或稍后在「设置 → 数据管理」补充
3. Key 仅保存在本机 localStorage，不上传任何服务器

## 技术栈

TypeScript + React 18 + CSS Modules + Zustand + rspack + pnpm。不引入重型 UI 框架，样式全部通过 CSS 变量做主题化。

## 目录结构

```
src/
  app/            应用入口、主题与配色预设
  components/     界面组件（聊天区、输入区、设置、弹窗、引导）
  i18n/           中英文文案
  services/
    api/          请求与 SSE 事件解析
    chat/         会话状态、消息、草稿、队列、记忆
    export/       Word 导出（手写最小 OOXML 包，无第三方 docx 依赖）
    usage/        token 统计、官方单价与闲峰时段判定
    logs.ts       脱敏日志
    settings.ts   本地设置读写
```
